# Accountancy Revision Room

A static, offline-capable Class XII Accountancy practice site modeled on the earlier Business Studies Revision Room's calm visual language. It covers the supplied 5 October 2026 exam scope: seven partnership chapters, issue of shares, accounting ratios, company financial statements, financial statement analysis, and comparative/common-size statements. Cash flow and debentures are excluded.

The bank contains 36 original, extended questions (three per chapter), each with a worked solution. Progress is stored only in the browser's local storage. No source exam papers or worksheets are copied into this site.

Open `dist/index.html` in a browser or serve the `dist` directory with a static file server.
